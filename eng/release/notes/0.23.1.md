# Runic editor extensions 0.23.1

A patch release for the Visual Studio Marketplace only: no functional change to
either extension. The [0.23.0 release](https://github.com/Runic-Artifex/runic-editors/releases/tag/v0.23.0)
reached the VS Code Marketplace, but the Visual Studio Marketplace refused its
VSIX: VsixPublisher requires the extension's description to be shorter than 280
characters (`VsixPub0024`), and 0.23.0's had 387. The 0.23.0 VSIX is attested
in its GitHub release and can't change, so 0.23.1 carries the shorter
description. The full description stays in the Marketplace overview.

| Asset | Extension | Version |
| --- | --- | --- |
| `runic-devkit.vsix` | VS Code, **Runic DevKit** (`runic-artifex.runic-devkit`) | `0.23.2000` |
| `runic-devkit-vs.vsix` | Visual Studio 2026, **Runic DevKit** (`RunicArtifex.DevKit.VisualStudio`) | `0.23.1.1000` |
| `SHA256SUMS` | `sha256sum` lines of both VSIX files | |

## Visual Studio

- **A Marketplace description under 280 characters.** The VSIX manifest's
  description is shortened from 387 to 267 characters; it still says what
  Runic DevKit is and that it replaces Runic MF2 Translations.
- **The release checks it before publishing.** `package.py --check-source`
  (CI) and the release workflow's candidate job, also in a dry run, now refuse
  a Visual Studio VSIX whose description is missing or 280 characters or
  longer, before anything is published.

## VS Code

Unchanged. The VS Code Marketplace keeps 0.23.0 (`0.23.1000`); 0.23.1 is not
published there. This release's `runic-devkit.vsix` (`0.23.2000`) has the same
features as 0.23.0's; install either.

## Stores

Runic DevKit for Visual Studio is on the Visual Studio Marketplace as
[runic-artifex.runic-devkit-vs](https://marketplace.visualstudio.com/items?itemName=runic-artifex.runic-devkit-vs)
(`0.23.1.1000`), published from this release's VSIX by trusted publishing.
Runic DevKit for VS Code stays on the VS Code Marketplace as
[runic-artifex.runic-devkit](https://marketplace.visualstudio.com/items?itemName=runic-artifex.runic-devkit)
(`0.23.1000`). Runic DevKit isn't on Open VSX: in VSCodium, Cursor or Windsurf,
install `runic-devkit.vsix` from this release or 0.23.0.

Both extensions are still tested with `dotnet-runic-translations` 0.15.1, as in
0.23.0.

## Verifying

```sh
sha256sum --check SHA256SUMS
gh attestation verify runic-devkit.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
gh attestation verify runic-devkit-vs.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
```

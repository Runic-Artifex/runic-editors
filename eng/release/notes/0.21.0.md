# Runic editor extensions 0.21.0

Part of the Runic 0.21 release train: it belongs to
[Runic Translations 0.13.0](https://github.com/Runic-Artifex/runic-translations-sdk/releases/tag/v0.13.0)
and [Runic SDK 0.21.0](https://github.com/Runic-Artifex/runic-sdk/releases/tag/v0.21.0).
Update the extensions together with the SDK: Runic SDK 0.21.0 renames the format ID
of the development source map, which the ViewModels view reads from 0.21.0 on.
Nothing is published to an extension marketplace: install a VSIX from this release.

| Asset | Extension | Version |
| --- | --- | --- |
| `runic.vsix` | VS Code, **Runic** (`runic-artifex.runic`) | `0.21.1000` |
| `runic-translations-visualstudio.vsix` | Visual Studio 2026, **Runic MF2 Translations** (`Runic.Artifex.Translations.Rmf2`) | `0.21.0.1000` |
| `SHA256SUMS` | `sha256sum` lines of both VSIX files | |

## VS Code

- The ViewModels view reads the development source map in both of its format IDs:
  `runic.views.bridge-sources/1`, which runic-sdk 0.21 writes, and
  `runic-bridge-sources/1`, which 0.20 apps write. Other versions are still rejected.
  Apps built with either SDK version show their ViewModels and Bridge members
  ([#8](https://github.com/Runic-Artifex/runic-editors/pull/8)).

## Visual Studio

No changes; the Visual Studio 2026 extension is released with the train's version.

## Language server

Neither extension bundles a language server: each runs the workspace's
`dotnet-runic-translations` tool. This release is tested against
`dotnet-runic-translations` 0.13.0 from NuGet, and the VS Code extension bundles
that release's `runic.json` schema (unchanged from 0.12.0). Translations 0.13.0
changes nothing the extensions use in the `lsp` protocol or the settings. Its
`xliff import` takes the document with `--input`; the **Import XLIFF (dry run)**
command still passes `--source`, which 0.13.0 keeps as a hidden alias, so it works
with both 0.12.0 and 0.13.0. Use the version of the project's `Runic.Translations`
packages:

```sh
dotnet tool install dotnet-runic-translations --version 0.13.0
```

## Compatibility

- Runic SDK: apps built with 0.20 and 0.21 both work, including the ViewModels view.
- Runic Translations: tested with 0.13.0; 0.12.0 workspaces keep working. For 0.11.0
  and older, use the VSIX files attached to that Translations release.

## Verifying

```sh
sha256sum --check SHA256SUMS
gh attestation verify runic.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
gh attestation verify runic-translations-visualstudio.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
```

The release workflow takes both VSIX files from the successful CI run of the
released commit and checks them by hash before attesting them.

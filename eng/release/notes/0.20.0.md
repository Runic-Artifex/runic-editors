# Runic editor extensions 0.20.0

The first release from runic-editors. Up to 0.11.0 the extensions were released
with [Runic Translations](https://github.com/Runic-Artifex/runic-translations-sdk/releases);
they now follow the Runic release train. 0.20.0 belongs to
[Runic Translations 0.12.0](https://github.com/Runic-Artifex/runic-translations-sdk/releases/tag/v0.12.0)
and [Runic SDK 0.20.0](https://github.com/Runic-Artifex/runic-sdk/releases/tag/v0.20.0).
Nothing is published to an extension marketplace: install a VSIX from this release.

| Asset | Extension | Version |
| --- | --- | --- |
| `runic.vsix` | VS Code, **Runic** (`runic-artifex.runic`) | `0.20.1000` |
| `runic-translations-visualstudio.vsix` | Visual Studio 2026, **Runic MF2 Translations** (`Runic.Artifex.Translations.Rmf2`) | `0.20.0.1000` |
| `SHA256SUMS` | `sha256sum` lines of both VSIX files | |

## VS Code: one Runic extension

([runic-editors#2](https://github.com/Runic-Artifex/runic-editors/issues/2), #5)
The Translations extension, Runic MF2 Translations (`runic-artifex.runic-translations`,
`runic-translations.vsix`), became **Runic** (`runic-artifex.runic`, `runic.vsix`),
which adds Runic SDK features in workspaces with a Runic SDK project: the Dev Session
view and status bar item for `dotnet runic dev`, F5 of the Window, the Doctor view,
quick fixes for Runic diagnostic codes and the ViewModels view. A Translations view
shows `runic-translations status` coverage per locale.

VS Code installs Runic next to the former extension; uninstall
`runic-artifex.runic-translations` afterwards. The former `runicTranslations.*`
settings still apply while the new `runic.*` ones are not set, and the former
command IDs still run. See [Moving from Runic MF2 Translations](https://github.com/Runic-Artifex/runic-editors/blob/v0.20.0/vscode/README.md#moving-from-runic-mf2-translations)
and the [changelog](https://github.com/Runic-Artifex/runic-editors/blob/v0.20.0/vscode/CHANGELOG.md#0200).

## Visual Studio

The Visual Studio 2026 extension keeps its identity and features; it is now built,
tested and released here.

## Language server

Neither extension bundles a language server: each runs the workspace's
`dotnet-runic-translations` tool. This release is tested against
`dotnet-runic-translations` 0.12.0 from NuGet, and the VS Code extension bundles
that release's `runic.json` schema (unchanged from 0.11.0). Use the version of
the project's `Runic.Translations` packages:

```sh
dotnet tool install dotnet-runic-translations --version 0.12.0
```

## Verifying

```sh
sha256sum --check SHA256SUMS
gh attestation verify runic.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
gh attestation verify runic-translations-visualstudio.vsix -R Runic-Artifex/runic-editors \
  --signer-workflow Runic-Artifex/runic-editors/.github/workflows/release.yml
```

The release workflow takes both VSIX files from the successful CI run of the
released commit and checks them by hash before attesting them.
